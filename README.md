# Gates of Hell Conquest Editor

This tool helps you manage a Gates of Hell campaign file without editing game data by hand. It gives you a simple interface for adjusting squads, inventories, and vehicle appearance in a campaign.

## What this project does

The editor is designed for quick, guided changes to a campaign save. Instead of working directly in raw files, you can use the built-in tools to:

- move or swap units between squads
- resupply units and squads with the right equipment
- add missing squad members
- clean up vehicle damage and markings
- update campaign data through a simple desktop interface

## Features

### Unit Manager
Use this tab to manage your forces.

- move a soldier from one squad to another
- exchange one soldier with another soldier in a different squad
- review unit type and name before making changes

This is useful when you want to reorganize your campaign forces without manually editing the campaign structure.

### Inventory Manager
Use this tab to handle equipment and resupply.

- resupply a single selected unit
- resupply an entire squad
- resupply all units in the campaign
- add missing squad members if needed
- check resources and current inventory state

This helps keep units ready for action and avoids manual inventory fixes.

### Vehicle Appearance
Use this tab to edit how vehicles look in the campaign.

- remove visible armor damage
- update vehicle numbering and marking style
- check whether a vehicle has armor or an enumerator section

This is useful for making vehicles look cleaner, more accurate, or more consistent with your campaign setup.

## How to use it

### Run the app from source

1. Open the project folder in Python.
2. Run the app:
   - Python: `python main.py`
   - or with uv: `uv run main.py`
3. In the app, choose the game install directory and campaign file you want to edit.
4. Select the tab you want to use:
   - Unit Manager for squad changes
   - Inventory Manager for resupply and equipment
   - Vehicle Appearance for vehicle visuals
5. Make your changes and save them to the campaign file.

### Build it into a standalone executable

If you want to share or run the program without Python installed, build it into a single executable file:

```bash
uv run pyinstaller --onefile --windowed --name "Gates-of-Hell-Conquest-Editor" src/main.py
```

This creates a standalone Windows app in the build output folder. The executable will be generated by PyInstaller and can then be run directly.

## Notes

This project is focused on making campaign editing easier and safer for everyday use. It is best suited for users who want a visual, guided way to update campaign data without dealing with the underlying game files directly.
